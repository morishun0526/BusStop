# バス接近（iPhone 用・無料）

お気に入りのバス停に「あと何分でバスが来るか」を表示するアプリです。
iPhone のホーム画面に追加して、ふつうのアプリと同じように使えます（PWA）。
**費用は 0 円**です（GitHub の無料機能だけで動きます）。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | お気に入りのバス停一覧。各バス停の「次のバスまであと何分」も表示 |
| 下段 ① 🔍 検索 | 上の検索ボックスに **バス停名**（漢字・ひらがな・一部でも可）を入れると全国のバス停から候補を表示。何も入れなければ都道府県別のバス会社一覧 → 会社を選ぶとバス停一覧（五十音順・あかさたな索引つき） → バス停を選ぶと到着予測 |
| 到着予測画面 | 「あと◯分」を大きく表示し、このあとのバスも一覧表示。右上の ☆ をタップすると点灯してお気に入りに追加 |
| 下段 ② ✏️ 編集 | お気に入りの右側に ⊖ が出て、タップで削除。右端の ＝ をドラッグして並べ替え |

- 30 秒ごとに自動更新します。
- バス会社がリアルタイム運行情報を公開している場合は遅れを反映します（「3分遅れ」などと表示）。公開していない会社は時刻表から計算します。
- 時刻表データは毎日 午前3時に自動で最新化されます。

## 公開手順（初回だけ・約15分）

1. **GitHub アカウントを作る**（無料）: https://github.com/signup
2. **リポジトリを作る**: 右上「＋」→「New repository」。名前は例えば `bus`、**Public** を選んで「Create repository」。
3. **ファイルをアップロード**: 「uploading an existing file」をクリックし、zip を展開してできたフォルダを開いて、**中にあるもの全部**（`.github` `web` `scripts` `extras` `test` フォルダと `README.md` など）をまとめて選んでドラッグし、「Commit changes」。
   - フォルダごと（外側のフォルダごと）ドラッグしないでください。リポジトリのトップに `.github` と `web` が直接並んでいる状態が正解です。
4. **確認**: リポジトリのトップで `.github` → `workflows` → `deploy.yml` と開けることを確認します。無い場合は「Add file」→「Create new file」でファイル名に `.github/workflows/deploy.yml` と入力し、同梱の同名ファイルの中身を貼り付けて「Commit changes」。
5. **Pages を有効にする**: リポジトリの「Settings」→ 左の「Pages」→「Source」を **GitHub Actions** に変更。
6. **初回のデータ取り込み**: 「Actions」タブ → 左の一覧の「データ更新と公開」をクリック → 右側に出る「Run workflow」→ 緑の「Run workflow」。全国分の取り込みで数十分かかります。緑のチェックが付けば完了。
7. **iPhone に入れる**: Safari で `https://<GitHubのユーザー名>.github.io/bus/` を開き、共有ボタン →「ホーム画面に追加」。

## 都営バス・東急バス・大阪シティバス

| 会社 | 内容 | 必要な作業 |
|---|---|---|
| 都営バス | 時刻表＋バスの現在位置から遅れを推定（「◯分遅れ」「2つ前の停留所」） | なし（自動で取り込まれます） |
| 東急バス | 時刻表から計算（リアルタイムの遅れは非対応） | 下の「ODPT のキー登録」 |
| 大阪シティバス | データ非公開のため、公式の接近情報サービスを開くボタン（☆でお気に入りにも追加可） | なし |

### ODPT のキー登録（東急バス用・無料・初回だけ）

1. 「公共交通オープンデータセンター 開発者サイト」 https://developer.odpt.org/ でユーザー登録します（メールアドレスで無料登録。承認まで数日かかることがあります）。登録時に表示される利用規約・データのライセンス（公共交通オープンデータ基本ライセンス）を確認してください。
2. ログイン後のページに表示される **アクセストークン**（英数字の長い文字列）をコピーします。
3. GitHub のリポジトリで「Settings」→ 左の「Secrets and variables」→「Actions」→「New repository secret」。
   - Name: `ODPT_KEY`
   - Secret: コピーしたアクセストークン
   →「Add secret」。
4. 「Actions」タブ →「データ更新と公開」→「Run workflow」で取り込み直すと、東急バスが一覧に出ます。

**東急バスが出ないとき**: アプリの「検索」画面を何も入力せずに一番下までスクロールすると、「取り込めなかった会社」とその理由が赤字で表示されます。
- 「ODPT_KEY が未設定です」→ Secret の名前が `ODPT_KEY`（半角大文字）か確認し、Actions で「Run workflow」をやり直してください。
- 「HTTP 403」「HTTP 401」→ アクセストークンが違うか、まだ有効になっていません。開発者サイトでトークンを確認し、Secret を貼り直してください（前後の空白に注意）。
- それ以外 → 表示された文面を Claude に伝えてください。Actions の実行ログの「全国のバス時刻表を取得・変換」の中にも `tokyu` から始まる詳しい記録があります。

キーは GitHub の中だけで使われ、公開されるアプリやデータには含まれません。キーを登録しなくても、東急バス以外はそのまま動きます。

### 会社を追加・削除したいとき

`scripts/sources.json` に書かれています。不要な会社はその `{ … }` のかたまりを消せば一覧から外れます。

## 知っておいてほしいこと

- **対応しているバス会社**: 国の「GTFSデータリポジトリ（gtfs-data.jp）」で時刻表を公開している事業者（主に地方の路線バス・コミュニティバス、全国で数百）と、上の都営バス・東急バス・大阪シティバスです。データを公開していない会社は一覧に出てきません。
- **東急バスの曜日ダイヤ**: 平日／土曜／休日の区分を祝日カレンダーと年末年始（12/30〜1/3 を休日扱い）で当てはめています。お盆などの特別ダイヤは反映されない場合があります。
- **リアルタイム**: 運行情報を公開している会社のみ。会社によってはブラウザから直接読めない設定のことがあり、その場合は自動で時刻表表示になります（画面下に「時刻表で表示」と出ます）。リアルタイムを使いたい場合は `extras/rt-proxy-worker.js` を Cloudflare Workers（無料）に置き、`web/config.js` の `RT_PROXY` にその URL を設定してください。
- **お気に入り**はその iPhone の中に保存されます。
- 表示する時刻は予測です。道路状況で前後します。
- データの出典表示: GTFSデータリポジトリ、公共交通オープンデータセンター／各バス事業者（各データのライセンスに従います）。

## 中身

```
web/                  アプリ本体（HTML / CSS / JavaScript、ライブラリ不使用）
scripts/build_data.py 時刻表データを取り込み、アプリ用に変換
scripts/sources.json  追加の会社（都営バス・東急バス・大阪シティバス）の設定
.github/workflows/    毎日の自動更新と公開
extras/               （任意）リアルタイム情報の中継プログラム
test/                 手元確認用（test/preview.sh で架空データのデモが動きます）
```
